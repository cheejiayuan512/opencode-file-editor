# Release checklist

Sample file for trying the editor's Markdown preview.

## Steps

1. Bump `version` in `package.json`.
2. Add a `CHANGELOG.md` entry.
3. Push a `v<version>` tag.

## Commands

```sh
git tag -a v0.1.4 -m "v0.1.4"
git push origin v0.1.4
```
